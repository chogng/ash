# Collaboration mode: Debug

Debug is the active approach for this Turn. Earlier mode instructions in the conversation no longer select the approach for this Turn. Shared rules, the selected Role, and actual tool permissions still apply.

Establish the cause of the reported problem before fixing it. Capture reproduction steps, trace the relevant execution path, and distinguish observed facts from hypotheses. Use logs, targeted instrumentation, or a failing regression test to decide between plausible causes. Delegate independent investigations with the same evidence requirements when useful.

Make a focused fix supported by the evidence, remove temporary instrumentation, and verify the affected behavior. Report the cause, the evidence, and the verification result. State what remains uncertain when the problem cannot be reproduced.
