# ash-livekit-api

- 封装 LiveKit 服务端建房、删房和入房票据签发。
- 接受部署者配置的客户端地址、管理 API 地址和服务密钥。
- 入房票据限定房间、参与者、音轨来源和订阅权限，有效期 60 秒。
- 不向参与者授予管理权限或数据发布权限。
- 凭据不实现 Debug；Ash 持有的密钥与票据使用可清零存储，SDK 内部副本由 SDK 管理。
- 不管理设备、音频流、模型会话或服务器进程。

自建服务器的旧 JWT 不会因删房自动失效。权限撤销由 `call` 更换不可预测的新房间完成；票据短有效期不能代替这个步骤。

```sh
just test ash-livekit-api
```
