# Advisor

- 提供 `advisor` 工具，向当前 Turn 已选定的模型咨询。
- 只返回建议，不提供工具，不执行动作，不递归调用顾问。
- 管理[咨询提示词](templates/instructions.md)，在编译时嵌入。
- 校验问题并限制每个 Turn 的调用次数。
- 委托 Core 固定上下文、处理附件、取消调用并记录用量。
- 通过既有工具执行记录恢复；已开始但结果未知的调用不自动重发。

默认每个 Turn 最多咨询 3 次，每次最多输出 2048 token。可配置范围分别为 1–16 次和 256–32768 token。已有压缩记录会沿用；剩余上下文超出顾问模型窗口时返回错误。

验证：`just test ash-advisor`。
