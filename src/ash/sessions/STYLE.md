# Sessions 设计与样式

本文是 Sessions 的设计规范，适用于 `src/ash/sessions/**` 及其他目录中专供 Sessions 使用的界面；不继承 Workbench 的视觉规则。

修改 UI 时落实受影响的要求；本文不代表现有界面已全部符合规范，状态、权限和生命周期仍遵守所属模块契约。

## 样式边界

| 层级 | 适用范围 | 样式依据 |
| --- | --- | --- |
| IDE | 常规 Workbench 窗口、导航、编辑与工具界面 | IDE 规范与所属组件 |
| Agent Window（Sessions） | 窗口框架、标题栏、页面导航、账户入口和通用界面 | 本文与 Sessions 所属组件 |
| 独立页面 | Design 等页面的内容、工具和页面所属浮层 | 页面专属规则；未规定的部分采用本文 |

- 三层分别定义外观，共用控件或主题服务不要求共用样式。
- 页面规则只作用于页面拥有的组件，不能影响窗口框架、其他页面或 IDE。
- 样式归属按组件用途与拥有方判断，页面菜单挂在窗口根节点下仍属于页面。
- 切换页面不改变窗口皮肤，也不能残留上一页面的样式。
- 共享控件拥有结构、交互状态和生命周期，调用方通过外观变体、主题变量或专属样式标识选择外观。
- 单个页面的设计不得修改共享控件默认值或 IDE、Sessions 全局主题值。
- 窗口 CSS 限定到 `.ash-sessions-window`，页面 CSS 限定到页面组件或专属浮层。
- 只有多个页面确实需要的规则才进入 Sessions 通用样式；保留已有的页面差异。
- 页面专属外观仍须满足可访问性、键盘操作和生命周期要求。

## 工作与状态

- 当前会话内容与下一步操作占据主要注意力，导航、设置和执行细节降低强调程度。
- 待回应请求持续可见并说明要决定什么，后台进度保持克制，完成与失败保留明确结果。
- 新建会话、发送和当前状态位置稳定，条目整理动作可在悬停或键盘聚焦时出现。
- 等待、无内容、无搜索结果和加载失败分别说明原因与下一步，未提供的能力不显示可点击入口。
- 选中、键盘焦点、执行、待回应和禁用分别表达，状态不能只依赖颜色或透明度。
- 禁用控件说明不可用原因，状态徽标只表示真实待处理事项，不用装饰性圆点或持续闪烁。

## Session 与 Chat

Session 是工作上下文，Chat 是其中一段对话。

- 侧栏选择 Session，主区域呈现当前 Chat，Session 名称只在识别上下文的位置强调。
- 单 Chat 避免相邻标题重名，多 Chat 保留各自标题与关闭入口，Session 标题表达共同上下文。
- Chat 数量仅用于理解或切换多段对话，时间、模型和目录不得与标题争夺注意力。
- 关闭 Chat、归档 Session 和停止执行分别命名与反馈。

## 导航

Activity Bar 用于产品页面导航，顺序与入口位置稳定，页面内工具放在对应内容附近。

| 项目 | 普通模式 | 紧凑模式 |
| --- | --- | --- |
| 图标 | 24px | 16px |
| 点击区域 | 36 × 36px | 28 × 28px |
| 按钮间距 | 8px | 4px |
| 高亮圆角 | 8px | 6px |

- 纵向与横向导航使用同一尺度，高亮覆盖点击区域，窄窗口调整布局而不单独缩小图标。
- 未选中背景透明，悬停轻量反馈，选中持续高亮且与悬停可区分。
- 有成对图形时未选中用线框、选中用实心，否则保留图形并用高亮表示选中。
- 同一入口使用同一图形，图标按钮提供可翻译的名称、tooltip 和可访问名称。
- 页面选择使用 `aria-current="page"`，账户入口表达菜单展开状态。
- 账户与窗口操作单独分组，位置稳定。

## 会话列表

| 项目 | 普通模式 | 紧凑模式 |
| --- | --- | --- |
| 单行条目高度 | 至少 48px | 至少 36px |
| 两行条目高度 | 至少 64px | 至少 48px |
| 搜索与新建控件 | 至少 36px 高 | 至少 28px 高 |

- 标题是首要信息，第二行只放工作摘要、来源或状态，时间与计数降低强调程度。
- 内容增长时条目增高，紧凑模式减少留白与辅助信息，保留状态、操作与文字可读性。
- 头像用于识别人、Agent 或工作来源，没有识别用途时省略。
- 搜索与新建位于列表入口，搜索框可伸缩，新建保持可发现。
- 选中使用连续轻量背景，错误与待回应有文字或形状辅助。
- 悬停动作不得挤动标题，键盘聚焦时同样可操作，触屏通过条目菜单提供。
- 保留选择与滚动位置，后台更新不自动重排用户正在操作的条目。

## 对话与输入区

- 对话按消息、进展、待决定事项和结果组织，长工具输出提供摘要与展开，失败和待回应内容直接可见。
- 正文保持适合阅读的行宽，代码、表格和差异可加宽并处理溢出。
- 输入区使用独立表面、12px 圆角、浅灰边框和浅阴影，聚焦只强调输入区。
- Chat 与 Code 输入卡片在悬停或内部聚焦时使用灰色边框与加深的柔和阴影，两者都结束后回落。
- 输入卡片不叠加蓝色边框或外圈，输入光标与按钮键盘焦点保持清晰。
- Sessions 通过显式外观变体定义输入框的悬停、聚焦、阴影与过渡，Workbench 保留自己的外观。
- 输入区随内容增高，达到可用空间限制后内部滚动，空会话与已有对话保持一致的控件关系。
- 输入区不预留固定的大块空白。
- 附件与上下文靠近编辑内容，模型与模式为辅助操作，发送与执行中的停止明确可见，未发送草稿保留。
- 自动滚动只跟随正在查看末尾的用户，向上阅读时保留位置并提示新内容。
- 权限请求紧邻对应操作，写清对象、影响和选项。
- 窄窗口优先保留对话与输入区，侧栏有明确开关，多 Chat 保留活动上下文与切换方式。

## 图标与点击区域

| 角色 | 图形尺寸 |
| --- | --- |
| 普通页面导航 | 24px |
| 工具动作、紧凑导航 | 16px |
| 行内元数据、辅助标识 | 12px；有 Compact 图形时使用对应版本 |

| 操作 | 最小点击区域 |
| --- | --- |
| 普通工具动作 | 28 × 28px |
| 紧凑工具动作 | 24 × 24px |
| 触屏操作 | 44 × 44px，包含留白 |

图形与点击区域分别设置，头像与内容插图按内容角色设计。

## 字体与留白

| 角色 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 18px | 600 |
| 空状态主标题，仅独立引导时使用 | 26px | 600 |
| 会话标题、正文、输入文字 | 13px | 400；强调标题用 600 |
| 控件标签 | 12px | 400 |
| 元数据 | 11px | 400 |
| 徽标计数 | 10px | 400 |

- 富文本与代码遵守所属内容的字号设置，紧凑模式不缩小正文与输入字号。
- 正文行高至少 1.4，长段落用 1.5，放大与缩放保留内容和操作。
- 间距使用 0、2、4、6、8、10、12、16、20、24、28、32、36、40px。
- 控件内部常用 4–8px，相关内容之间 8–12px，区块之间 16–24px，窗口布局与测量尺寸按实际约束计算。
- 使用已注册且符合本文尺度的 token，缺少时在所属位置注册。

## 圆角与边界

| 表面 | 圆角 |
| --- | --- |
| 小型工具按钮、标签 | 4px |
| 紧凑导航、紧凑输入控件 | 6px |
| 标题栏工具按钮、普通导航、搜索框、普通会话条目 | 8px |
| 对话输入区、独立浮层 | 12px |
| 有身份含义的头像、胶囊 | 全圆 |

- 圆角按组件角色与大小选择，同类组件一致，不按浮起程度推导。
- 普通边框与分隔线为 1px，焦点与状态标记以清晰可辨为准。
- 内部区块优先用留白分组，独立滚动或调整大小的区域可使用边界。

## 颜色与动效

- 颜色使用所属层或页面的语义 token，区分页面、辅助区域、输入表面、选中、悬停与状态。
- 选中使用轻量背景，不能直接套用强调按钮背景。
- 浅色、深色与高对比度主题下状态清晰，高对比度使用明确轮廓。
- 卡片静置时轻，悬停或聚焦时柔和浮起，持续操作时稳定，离开后回落。
- 浮起只改变边框与阴影，尺寸、内容位置和点击区域保持稳定。
- 过渡短暂、连续且可中断，快速交互从当前外观继续，尊重减少动态效果设置。
- 动效用于说明变化或维持位置感，不用循环明暗、缩放或位移模拟呼吸。
- 悬停与聚焦可共用表面反馈，键盘焦点仍须清晰，进度结束后保留最终状态。

## Tooltip

| 项目 | Sessions 要求 |
| --- | --- |
| 圆角 | 12px |
| 箭头 | 不显示 |
| 背景／前景 | 浅色、深色与高对比度默认黑底白字 |
| 高对比度边框 | 白色 |
| 普通边框、阴影、字号、行高、内边距 | 与共享 Workbench tooltip 一致 |

- 使用 `sessions.tooltip.background`、`sessions.tooltip.foreground`、`sessions.tooltip.border`，在窗口内映射，不修改 Workbench tooltip token 注册值。
- 外观集中在 [workbench.css](browser/media/workbench.css)，限定到 `.ash-sessions-window`。
- Tooltip 挂在窗口根节点下，selector 不依赖触发控件的后代关系。

## 页面菜单

| 菜单 | 外观 |
| --- | --- |
| IDE 右键菜单 | IDE 菜单样式 |
| Sessions 账户、窗口与通用右键菜单 | Sessions 菜单样式 |
| Design 画布右键菜单、工具下拉菜单 | 专属黑色表面与配套前景色 |
| 其他页面菜单 | 页面专属要求；未规定时采用 Sessions 菜单样式 |

- Design 菜单在普通浅色与深色主题下保留黑色表面，高对比度保持可读性与明确轮廓。
- 画布与工具菜单使用 `ash-design-menu`，其他菜单不得复制该标识或颜色。
- 颜色使用 `sessions.design.chromeBackground`、`sessions.design.chromeForeground`，普通主题背景为 `#181818`。
- 菜单浮层位于共享容器，selector 使用页面标识，不依赖画布后代关系。

实现入口：[designEditorWidget.ts](contrib/creator/browser/widget/designEditorWidget.ts)、[designToolsWidget.ts](contrib/creator/browser/widget/designToolsWidget.ts)、[designToolsWidget.css](contrib/creator/browser/widget/designToolsWidget.css)。

## 文案与可访问性

- 文案使用用户理解的动作与状态，英文用 sentence case，保留专有名称，文案、提示、错误和可访问名称接入所属端 NLS。
- 页面图标配名称提示，有空间的业务动作优先显示文字，删除、归档、关闭与停止使用明确动词。
- 所有操作可通过键盘完成，列表与导航按语义支持方向键，Tab 按逻辑顺序进入区域。
- 菜单与浮层关闭后恢复焦点，键盘焦点始终可见且与选中区分，鼠标交互不留下无意义的焦点装饰。
- 标题截断用省略号并提供完整 tooltip 与可访问名称，正文、权限请求和错误原因保留完整文本。
- 状态变化按紧急程度播报，流式输出不逐字打断用户。
- 新交互区域提供无障碍帮助，复杂内容提供可访问文本视图，并允许控制帮助提示播报。

## 修改与验证

- 规则随明确的产品设计决定更新，不为迁就现有实现反向改写，不记录逐次问题处理过程。
- 改动与评审写清所属层、目标组件、需要保留的页面差异及相关规则。
- UI 使用 Playwright 验证 Browser 与 Electron，通过 DOM、计算样式、焦点和可访问属性断言行为。
- 覆盖受影响的普通／紧凑模式、窄窗口、键盘操作、长标题、主题与任务状态。
- 输入卡片覆盖静置、仅悬停、仅聚焦、同时悬停与聚焦及全部结束；输入时移开鼠标仍浮起，过渡不挤动内容。
- 菜单覆盖鼠标与键盘打开、关闭后的焦点恢复、反复切换页面，确认样式不串用。
- 同类组件在 IDE、Sessions 和其他页面中保留各自外观，高对比度与减少动态效果设置均可用。
- 仅改文档时检查结构、链接和表述一致性，只报告实际运行的验证结果。
