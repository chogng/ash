# Remote Workspace Configuration

Optional SSH configuration syntax and snippets. Open ssh_config or ~/.ssh/config and use ssh-host or ssh-jump completion snippets. The extension provides editing support only; connection, authentication, terminal execution and host trust continue to use Ash Remote. It never reads SSH keys or connects to a host.

Disable or uninstall the package to remove its language and snippet contributions. Editor accessibility help and Keyboard Shortcuts remain available.
