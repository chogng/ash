# PDF 阅读、批注与 AI 内容接入

PDF Viewer 提供查看和批注，配套 PDF Reading 提供 AI 读取工具及阅读 Skill。两者都是可选独立包，解析留在扩展中，不需要通用文档编辑、排版或 Academy 文档模型。

## 当前实现

PDF Viewer 已有 PDF.js 渲染、25–400% 缩放与适合宽度、正文选择／复制、跨页搜索，以及高亮、墨迹和便签批注。批注由扩展自己的模型与撤销历史管理，通过窗口获授权的文件服务保存到 `<file>.pdf.ash-annotations.json`，不改写原 PDF。Chat 附件预览是只读输入，不读取 sidecar。未保存批注属于当前 pane，关闭前需要保存。

PDF Reading 的实现、限制与打包命令见 [AI 包说明](../ai/README.md)。调用链是：用户在 Chat 指定本地 PDF → 模型调用实际发现的 MCP 工具 → Ash 按当前策略审批 → 独立 Node 进程解析／渲染 → 现有工具结果和图像输入交给模型 → 回答引用物理 PDF 页码。文件不必在 Viewer 中打开。

| 部分        | 所有权                                                         |
| ----------- | -------------------------------------------------------------- |
| PDF Viewer  | 页面、交互、文本选区、批注模型、草稿与撤销历史                 |
| PDF Reading | PDF 字节快照、文字提取、页码／区域映射、页面图像及读取预算     |
| 现有宿主    | 安装、发现、MCP 调用审批、取消、模型连接、工具结果与图像传递   |
| 阅读 Skill  | 分批阅读、图文核对、版本一致性与页码引用，不提供权限或解析实现 |

## 工具行为

`pdf_read` 默认读取最多 5 页，可指定最多 20 页。结果包含源 SHA-256、页数、逐页文字、是否有文本层、截断与续读位置。后续请求携带 `expected_sha256` 可拒绝文件版本变化。区域使用旋转后页面左上角起算的归一化坐标，包含中心位于区域内的完整文字片段，不保证视觉阅读顺序。

`pdf_render_page` 返回指定页或区域的真实 PNG 及同源摘要，沿用 MCP 图像内容到模型图像输入的通道。扫描件没有文本层时返回明确的无文字信号，可由支持图像的模型阅读页面；没有 OCR。超大嵌入图片受渲染上限约束，结果明确说明可能省略，空白渲染不能据此判定原页空白。

仅当用户要求时，`include_saved_annotations` 才读取已保存 sidecar。版本 1 sidecar 不绑定源 PDF 摘要，结果标明批注可能过期；不读取或复制未保存草稿，不写 PDF 或批注。PDF 正文、图片文字和批注均为待分析材料，不是执行指令。

每次调用使用可终止 worker，限制文件大小、页数、文字和图片输出、并发及执行时间。取消会终止解析 worker。原生画布库随签名包压缩分发，启动时验证摘要和解压上限，使用私有临时目录并在正常退出时清理。

## 安装与授权边界

当前 registry 的 `editor` 包不能组合 MCP 与 Skill，所以 PDF Reading 作为独立 `plugin` 分发；不会因为安装阅读 Skill 就授予 Viewer 原生客户端权限。安装后的 MCP 由已有宿主发现，每次调用沿用 Ash 的精确参数审批。当前 registry MCP 没有独立启停开关，卸载包会使能力引用失效并移除 Skill。

MCP 子进程使用当前操作系统身份访问请求路径，并不继承 Viewer 文件服务的目录沙箱。工具只接受用户指定的本地绝对路径，不枚举目录、拉取 URL 或另建模型凭据。Chat 附件必须先通过已有附件／文件流程取得获授权的本地副本；这里没有新增附件自动落盘或选区发送界面。内容发送继续受现有模型策略控制。

## 验证与范围

`pnpm test:unit --run extensions/pdf-viewer/test/pdfReading.test.ts` 构建真实分发包并通过官方 MCP Client 调用其 stdio 进程，覆盖文字续读、源版本变化、旋转区域、页面／扫描图像像素、非法输入、批注显式选择、取消后恢复及正常关闭的临时资源清理。

Ash Desktop 自托管场景使用合成 PDF 与隔离 profile，通过真实签名仓库安装包，检查 MCP 与 Skill 发现，驱动 Chat 的文字和图像调用、物理页码引用及卸载后的工具目录。模型端使用可控 Responses 服务核对实际收到的文字、源摘要和 PNG；这证明调用与媒体链路，不代表真实模型的视觉语义质量评测。
