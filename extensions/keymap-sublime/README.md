# Sublime Text Keymap

Optional, declarative shortcuts for selection, multiple cursors, duplicate/delete line and inserting lines. macOS uses Command for the corresponding shortcuts.

Install through Extensions, then enable the extension. Disable or uninstall it to restore the existing keybindings. This package does not add modal editing or execute code.

Press Alt+F1 in the editor for accessibility help; Keyboard Shortcuts lists and lets you change these bindings.
