# GLM subscription account login

`ash-glm` owns four separate interactive accounts: BigModel and Z.AI Coding Plan and Start Plan. It reads existing ZCode credentials from `~/.zcode/v2/credentials.json` (or `ZCODE_DATA_BASE_DIR/.zcode/v2/credentials.json`). Coding Plan uses its account request key; Start Plan uses the matching active region's ZCode JWT. The user does not enter a subscription key.

ZCode credentials are read for each model request and are never copied into Ash or written back. Ash reuses a ZCode subscription only when its account and Coding Plan request key are complete and readable. Otherwise it uses its own saved credential or offers browser authorization and polling, without changing ZCode's file. After authorization, the driver asks `ash-backend-client` to obtain a model request credential from the corresponding provider business API. Only the account ID, optional display metadata, credential revision, and model request credential are saved in the profile `SecretStore`. OAuth poll tokens and account access tokens stay within the login attempt.

`ash-login` owns login IDs, cancellation, account state, and logout. This crate owns the provider protocol and private credential lifecycle. Logout disconnects only the selected Ash connection, deletes its internal credential, and persists a connection-specific disconnect marker in the profile SecretStore. It leaves ZCode credentials untouched. Refresh, external account changes, and process restart respect that marker; an explicit login clears it. `ash-model-provider` reads the matching account and request target together for each model invocation. The four connections never share stored credentials; their models use the shared `glm` vendor ID.

The App Server exposes all four through `account/login/start`, `account/read`, `account/logout`, and the existing login completion notifications. Quota is exposed through `account/rateLimits/read`; Coding Plan uses its monitor API, while Start Plan reports active billing balance buckets. The account is checked again before publication. Coding Plan's quota response does not establish a plan tier, so it remains unknown.
