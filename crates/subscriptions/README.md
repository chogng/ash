# `ash-subscriptions`

本 crate 负责订阅账户和外部凭证来源模型目录的后台观察周期。它从 `ash-login` 读取脱敏账户状态，按当前账户触发资料和模型刷新；外部来源通过 catalog port 读取不含秘密的当前凭证范围，不创建登录账户。共享后台每 60 秒检查本机身份变化，每 5 分钟刷新远程目录。

外部凭证范围变化或消失时，先发布退役通知，再尝试发现；刷新后再次校验身份，丢弃迟到的旧凭证结果。同范围失败保留 manager 的有效缓存，观察器等下一次远程周期再试，不让每个窗口启动独立网络轮询。

账户登录、凭据和脱敏状态仍由 `ash-login` 与供应商适配器负责；模型发现由 `SubscriptionCatalog` 的实现负责。App Server 装配观察器，并把 `ModelsUpdate` / `ExternalModelsUpdate` 转成对外通知，不保存观察周期或重试状态。
