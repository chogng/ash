# `ash-user-verification`

提供本机硬件级生物识别确认与私钥签名能力，独立于 RPC 传输、UI 呈现和远端服务业务逻辑。

## 核心职责

- **保管硬件级私钥**：在平台安全芯片（如 macOS Secure Enclave）中生成并保管非对称签名私钥（P-256 ECC），私钥不出硬件，仅提供安全导出的公钥。
- **调起生物识别确认**：在敏感操作发生时，要求用户进行生物识别（Touch ID / 平台生物识别），由底层硬件安全策略强制执行访问控制。
- **生成可验证签名证明**：对服务端的随机挑战串（Challenge）生成 ECDSA P-256 签名（Proof），供远端服务校验用户现场授权。
- **跨进程生命周期与取消控制**：提供基于文件锁的账号级硬件操作互斥保护，支持在认证等待期间通过 RequestGuard 随时安全中断并关闭系统弹窗。
