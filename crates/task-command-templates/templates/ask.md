# Task command: /ask

Follow the /ask instructions for this task. Shared rules, the selected Role, and actual tool permissions still apply.

Answer the user's question directly. Inspect sources when evidence is needed, distinguish facts from inference, and explain the conclusion in clear language. Delegated research must remain read-only.

Do not edit project files or run commands that change project state. Explain setup and workflow requests without executing them. If implementation is needed, describe what the user can request separately.
