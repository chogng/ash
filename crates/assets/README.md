# 素材领域

本 crate 拥有跨产品图片素材的入库校验、不可变版本、目录整理和上传生命周期。Design、Library 与生成任务消费同一领域；本 crate 不保存编辑器选区、布局、裁切或撤销历史。

目前支持 PNG、JPEG、WebP 原件，单个文件最多 16 MiB。复用 `ash-utils-image` 的格式识别，使用图片解码器检查内容、限制解码内存并取得包含方向的显示尺寸；原始字节保持不变。模型输入的缩放、去元数据与转码策略不用于素材入库。

`AssetStore` 由 `ash-state::SqliteAssetStore` 实现。原件与版本在同一事务中发布，相同内容只保存一份；素材和版本身份由调用前确定的 UUID 表达。已登记版本不能改写，相同版本与内容的重复提交可恢复原结果。使用处保存确切版本，追加新版本不升级已有引用。

分块上传以连接与版本身份隔离，取消和连接关闭释放暂存内容；超过十分钟未活动的上传在下一次上传操作时清理。完整上传的完成请求消费暂存数据并原子发布，发布本身不可取消；连接中断造成结果未知时，通过素材和版本身份读取确认。已发布版本跨窗口与后端重启保留，当前没有素材删除或回收接口。

素材目录为每个素材返回最近发布的版本、添加时间、收藏状态和集合归属；目录与集合在同一读取事务中保持一致。收藏和集合归属按素材身份保存，版本追加不清除整理结果。集合删除只解除集合关系，保留原件、版本与收藏。已有版本 1 数据库迁移保留原始字节；历史版本没有记录的添加时间使用 0 表示未知。

当前已提供图片入库、读取、目录、收藏和集合；名称与来源搜索、分类和排序由 Library 页面处理。标签、独立缩略图、音视频处理和生成产物接入尚未实现。协议由 `ash-app-server-protocol` 定义，App Server 只分发请求。前端使用 `IAssetService`；Design 工作副本继续管理保存和冲突，并将采用的媒体带入可移动文件包。
