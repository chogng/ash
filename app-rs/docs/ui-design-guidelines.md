# Ash App UI 视觉规范

> 状态：Current。本文定义 Ash App 的视觉语言和组件配方。主题颜色体系由 [`Design Token`](../../docs/design-tokens.md) 维护，组件组合关系由 [`ash-ui-components/ARCH.md`](../ui-components/ARCH.md) 维护。

## 快速理解

Ash App 使用紧凑、克制、低噪声的桌面界面：信息密度高，但层级必须清楚；普通区域依靠表面色和留白区分，只有浮层使用阴影，只有模态弹窗使用遮罩。

| 场景 | 应有的感觉 | 主要手段 |
| --- | --- | --- |
| 工作区和侧栏 | 稳定、安静 | 低对比表面、细边界、紧凑间距 |
| 按钮、输入框和列表项 | 清楚但不过度突出 | 4–6px 圆角、明确的悬停/焦点/按下状态 |
| 右键菜单和临时浮层 | 轻量地浮在内容上方 | 10px 外壳圆角、阴影、无遮罩 |
| Dialog | 明确中断当前操作 | 全视口遮罩、10px 圆角、焦点锁定 |

## 1. 视觉原则

- **层级优先**：先用表面、留白和排版建立层级，再使用边框，最后才使用阴影。
- **紧凑但不拥挤**：控件高度以 28–34px 为主；相关内容靠近，不相关内容至少跨一个分组间距。
- **状态必须可辨认**：悬停、焦点、按下、选中和禁用不能只依赖同一种颜色变化。
- **浮层数量要少**：同一时刻只保留完成当前操作所需的最高层浮层。
- **一类组件一个配方**：相同层级的组件使用相同圆角、边框、阴影和排版，不按页面随意变化。

## 2. 基础标尺

### 2.1 间距

| 值 | 用途 |
| --- | --- |
| 2px | 菜单项之间的细小间隙、紧邻状态元素 |
| 4px | 图标与紧凑内容、内嵌控件间隙 |
| 6px | 右键菜单内边距、紧凑输入区域 |
| 8px | 控件内部图标/文字间距、常规横向间距 |
| 12px | 同一分组内的块间距 |
| 16px | 面板内容内边距、主要分组间距 |
| 24px | 大区域留白、Dialog 与视口的最小距离 |

新增样式优先从标尺选择最接近的值；偏离标尺必须来自明确的组件几何需要，不能只为单页视觉微调。

### 2.2 圆角

| 值 | 用途 |
| --- | --- |
| 0px | 与父表面齐边的区域 |
| 3px | 浮层内部的紧凑输入框 |
| 4px | 普通按钮、工具栏按钮、列表状态块 |
| 6px | 输入框、模式切换、紧凑内容卡片 |
| 10px | Dialog、ContextMenu 及其菜单项 |
| 全圆 | 状态点、圆形图标按钮、开关轨道 |

`6px` 是 ContextMenu 的内边距，不是它的外壳圆角；ContextMenu 和 Dialog 的外壳圆角都是 `10px`。

### 2.3 字体

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 辅助信息 | 11 / 16px | Regular | 状态、时间、次要元数据 |
| 次级正文 | 12 / 18px | Regular | 描述、提示、输入框文字 |
| 主正文 | 13 / 18px | Regular | 列表内容、说明文字、正文 |
| 控件与导航 | 13 / 18px | Medium | 按钮、当前模式、设置导航 |
| 强调控件 | 13 / 18px | SemiBold | ContextMenu 动作、Pane tab |
| 页面标题 | 18 / 24px | SemiBold | 设置页及模态内容标题 |

正文默认使用 Regular。动作、当前选择或短标签使用 Medium，标题和需要更强区分的短标签使用 SemiBold；不要使用 Bold 弥补层级或间距不足。字体族和基础字号由 `[gui]` 的 `interfaceFontFamily` 与 `interfaceFontSize` 决定，组件只选择字体角色。

### 2.4 边框与阴影

| 层级 | 边框 | 阴影 | 遮罩 |
| --- | --- | --- | --- |
| 基础表面 | 无或 1px 语义边界色 | 无 | 无 |
| 控件 | 1px，仅在需要表达边界或焦点时出现 | 无 | 无 |
| ContextMenu / 临时浮层 | 1px 语义边界色 | 单层柔和下落阴影 | 无 |
| Dialog | 1px 语义边界色 | `rgba(0,0,0,64)`、Y 8px、blur 24px | `rgba(0,0,0,72)` |

阴影只表达层级，不表达选中或焦点。普通 Pane、列表和工具栏不使用阴影。

## 3. 颜色使用

设计只引用语义角色，不固定亮色或暗色主题的 RGB：

| 角色 | 用途 |
| --- | --- |
| Canvas | 窗口和主工作区底色 |
| Surface | Pane、侧栏、设置页等内容表面 |
| Elevated Surface | 菜单、Dialog 等浮层表面 |
| Border | 区域边界、输入框边界、浮层描边 |
| Text / Muted Text | 主文字和次级文字 |
| Accent | 焦点、选中、当前操作 |
| Hover / Pressed | 指针悬停和按下反馈 |
| Danger | 删除、失败和不可逆动作 |

同一个视觉角色必须使用同一个主题语义色。不要在组件配方中写主题专属 RGB；遮罩和中性阴影是浮层配方的一部分，可以使用固定透明黑。

## 4. 交互状态

| 状态 | 视觉要求 |
| --- | --- |
| Resting | 保持最低必要对比，不制造无意义边框 |
| Hovered | 提升背景对比；不得改变布局尺寸 |
| Focused | 与 Hovered 可区分，使用焦点边界或明确的焦点表面 |
| Pressed | 比 Hovered 更实，反馈发生在按下期间 |
| Selected | 即使指针离开也能保持可见；不能只依赖 Hovered |
| Disabled | 降低强调度，同时移除按下和激活反馈 |
| Danger | 只用于危险动作的文字、图标或确认状态，不把整组普通动作染红 |

状态变化不得导致文字、图标或控件边界跳动。焦点样式必须支持键盘导航，不能只为鼠标悬停设计。

## 5. 组件配方

### 5.1 Dialog

| 项目 | 规范 |
| --- | --- |
| 位置 | 在全窗口视口中居中 |
| 视口安全距离 | 四周至少 24px |
| 外壳圆角 | 10px |
| 边框 | 1px 语义边界色 |
| 遮罩 | `rgba(0,0,0,72)` |
| 阴影 | `rgba(0,0,0,64)`、Y 8px、blur 24px |
| 标题 | 17 / 22px、Regular |
| 行为 | 焦点锁定在 Dialog 内；背景不能命中或激活；关闭后恢复原焦点 |

Dialog 只停止背景交互，不停止后台任务、终端输出、动画或数据更新。点击遮罩默认不关闭；取消行为必须由明确的关闭动作或 Escape 提供。

Settings 使用 `960×640` 的内容尺寸，QuickInput 使用 `660×470`；这些是内容布局，不改变 Dialog 外壳配方。

### 5.2 ContextMenu

| 项目 | 规范 |
| --- | --- |
| 宽度 | 140px |
| 菜单项高度 | 28px |
| 菜单项间距 | 2px |
| 视口边距 | 8px |
| 外壳内边距 | 6px |
| 外壳圆角 | 10px |
| 菜单项圆角 | 10px |
| 文字 | 13 / 18px、SemiBold |
| 图标 | 12px，图标与文字间距 8px |
| 遮罩 | 无 |

子菜单与父菜单使用同一配方。重命名等内嵌输入浮层使用 6px 外壳圆角和 3px 输入框圆角，不套用菜单项样式。

### 5.3 Button 与工具栏动作

| 类型 | 高度 | 圆角 | 用途 |
| --- | --- | --- | --- |
| 紧凑动作 | 28px | 4px | 菜单、工具栏、行内动作 |
| 常规动作 | 32px | 4–6px | 表单和页面主操作 |
| 图标按钮 | 28–32px | 4px 或全圆 | 关闭、更多、切换工具 |

一个动作只保留一个主视觉入口。图标和文字同时出现时使用 8px 间距；只有图标时必须提供可访问名称和悬停说明。

### 5.4 InputBox 与 SearchBox

- 常规高度使用 32–34px，圆角使用 6px。
- 水平内边距使用 8–10px；搜索图标与文字使用 8px 间距。
- Resting、Hovered、Focused 使用不同边界或表面状态，Focused 必须最明确。
- placeholder 使用次级文字色，不代替字段标签或错误说明。
- 错误状态使用 Danger 颜色，但不改变输入框尺寸。

### 5.5 列表与导航项

- 紧凑动作行使用 28px；常规导航行使用 32–34px。
- 图标、主标题、描述和尾部动作按同一基线排列。
- Selected 表示当前对象，Focused 表示键盘位置，两者必须能同时表达。
- 行内关闭、更多等动作不改变行高，也不挤压主标题的起始位置。

## 6. 布局与层级

- 同一分组内部使用 4–8px 间距，分组之间使用 12–16px。
- 面板内容默认使用 16px 内边距；大型页面可以使用 24px。
- 主操作靠近其影响的内容；危险操作与普通操作保持分隔。
- 浮层必须锚定到触发对象或窗口中心，不使用无来源的任意坐标。
- Dialog、ContextMenu、Dropdown 等浮层不得被父内容裁剪。

## 7. 使用检查

新增或修改界面时检查：

- 是否先选择了正确的层级：基础表面、锚定浮层还是 Dialog？
- 间距、圆角、字号是否来自本文标尺？
- 是否复用了语义颜色，而不是复制某个主题的 RGB？
- Hovered、Focused、Pressed、Selected、Disabled 是否都能独立识别？
- 浮层是否正确处理焦点、Escape、关闭和焦点恢复？
- 是否把只属于一个界面的特殊样式错误下沉成了通用组件默认值？

## 8. 落地边界

- `ash-ui-components` 提供组件能力和 `Style` 输入，不固定 Ash App 的具体视觉配方。
- 具体界面在自己的组合文件中按本文构建样式；重复配方通过该界面拥有的样式工厂收敛。
- 语义颜色属于主题 token；字体等需要跨主题长期保存的偏好才进入 `[gui]`；焦点、命中和手势属于组件交互。
