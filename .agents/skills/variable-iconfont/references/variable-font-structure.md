# Variable font structure

The generated font is a TrueType-flavored OpenType variable font.

Important tables:

- `fvar`: declares the variation axis and its min/default/max values.
- `gvar`: stores glyph outline deltas across the axis.
- `STAT`: describes axis metadata for consumers.
- `glyf`/`loca`: store the base TrueType outlines.
- `cmap`: maps Unicode code points to glyph names.
- `hmtx`/`HVAR`: store horizontal metrics and variation support.

For the default manifest:

- axis tag: `ANIM`
- minimum: `0`
- default: `0`
- maximum: `100`

`ANIM=0` corresponds to the start master and `ANIM=100` to the end master. Intermediate values are generated by outline interpolation, not by storing frame-by-frame SVGs.
